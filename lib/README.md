# lib

Launcher ilk calistirmada asagidaki bagimliliklari otomatik hazirlar:

- `sqlite-jdbc-3.53.4.0.jar`
- `slf4j-api-1.7.36.jar`
- `flatlaf-3.7.2.jar`
- `flatlaf-3.7.2.jar.sha256`

SQLite JDBC ve SLF4J API sabit SHA-256 ile, FlatLaf ise Maven Central `.sha256` dosyasi ile dogrulanir.
