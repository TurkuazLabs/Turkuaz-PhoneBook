# Guvenlik Politikasi

Bu politika **Turkuaz PhoneBook** (Turkce urun adi: **Turkuaz Telefon Rehberi**) icin gecerlidir.

[English security policy](./SECURITY.md)

## Desteklenen surum

Guvenlik duzeltmeleri aktif olarak desteklenen en yeni GitHub Release surumune uygulanir. Eski surum kullananlar, daha once duzeltilmis olabilecek sorunlari bildirmeden once en yeni release'e guncellemelidir.

## Hassas veri

Public issue veya discussion icine gercek kisi veritabani, telefon numarasi, e-posta, senkron tokeni, backup DB veya kisisel ekran goruntusu yuklemeyin. Sorunu mumkunse bos veya test verisiyle tekrar uretin.

## Mobil LAN senkronu

Mobil senkron varsayilan olarak kapali gelir ve yalniz guvenilir yerel ag icin tasarlanmistir. `8787` portunu Internet'e acmayin ve senkron tokenini guvenmediginiz cihaz veya kisilerle paylasmayin.

## Guvenlik acigi bildirimi

Repository'de GitHub Security Advisories / private vulnerability reporting etkinse bu ozel kanali kullanin. Exploit ayrintilarini, tokenleri, ozel kullanici verilerini veya diger hassas bilgileri public issue icinde yayinlamayin.
